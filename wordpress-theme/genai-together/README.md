# GenAI Together WordPress block theme

This theme reproduces the approved design using editable WordPress blocks.

## Editable content

Use the supplied Team member card and Research output card patterns for content that changes. Use normal Image blocks to upload portraits, logos and output covers. Keep events unpublished or remove their cards until details are confirmed.

## Preview before administrator access

1. Zip the `genai-together` folder.
2. In a test WordPress installation or WordPress Playground, upload and activate the zip as a theme.
3. Create pages for Home, Team, Collaborators, Resources and Contact; set Home as the static front page.
4. Use Site Editor to configure navigation and template parts.

## Production requirement

The existing WordPress.com account needs an Administrator/Site Editor role and a plan that permits installing or activating custom themes. If that is not available, retain the Vercel implementation.
